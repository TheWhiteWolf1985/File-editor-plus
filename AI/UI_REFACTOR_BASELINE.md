# UI Refactor Baseline (Step 0)

Questo documento definisce la baseline documentale per il refactor UI, usando come riferimento i file in `.temp/`.

## Reference

- Layout/markup di riferimento: `.temp/index.html`
- Stili di riferimento: `.temp/src/styles/editor.css`

## Checklist Manuale Screenshot Baseline

- [ ] Aprire la UI con tema `dark` attivo.
- [ ] Catturare screenshot full-page baseline in `dark`.
- [ ] Catturare screenshot dettaglio `tree` in `dark` con stato `hover`.
- [ ] Catturare screenshot dettaglio `tree` in `dark` con stato `selected`.
- [ ] Passare al tema `light`.
- [ ] Catturare screenshot full-page baseline in `light`.
- [ ] Catturare screenshot dettaglio `tree` in `light` con stato `hover`.
- [ ] Catturare screenshot dettaglio `tree` in `light` con stato `selected`.
- [ ] Verificare coerenza spacing, typography e contrasto tra `dark`/`light`.
